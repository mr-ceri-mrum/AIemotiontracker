# AI Дневник Эмоций (Mental Wellness Tracker)

Приложение для отслеживания эмоционального состояния с AI-анализом и рекомендациями для улучшения ментального здоровья.

## Описание проекта

AI Дневник Эмоций — это веб-приложение, где пользователи могут ежедневно делиться своими мыслями и переживаниями. Искусственный интеллект анализирует эмоциональное состояние пользователя и предоставляет персонализированные рекомендации для поддержания позитивного настроя и психологического благополучия.

## Возможности

- **Дневник эмоций**: Ежедневные записи с анализом эмоционального состояния
- **Визуализация эмоций**: Графическое отображение эмоционального профиля
- **Персонализированные рекомендации**: Советы для улучшения ментального здоровья
- **История записей**: Отслеживание эмоционального состояния в динамике
- **Инсайты и тренды**: Аналитика эмоционального состояния

## Бизнес-модель

- **Базовая версия**: Бесплатный доступ к основному функционалу
- **Премиум подписка**: Расширенная аналитика, персонализированные рекомендации от психологов, библиотека упражнений
- **Партнерские программы**: Рекомендации профессиональных психологических курсов и ресурсов

## Технологии

- **Frontend**: React, Tailwind CSS, Recharts
- **Иконки**: Lucide React

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/mr-ceri-mrum/AIemotiontracker.git
cd AIemotiontracker
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение:
```bash
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)
